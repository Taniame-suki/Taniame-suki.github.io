这个网站最初只是一张空白页。

我试过几个现成的模板，功能都很齐全，但打开编辑器的那一刻，总会先花半小时研究“这个模块应该放在哪里”。后来我意识到，自己真正想要的并不是一个功能完整的平台，而是一个能安静放字的地方。

于是有了现在这个版本：用 Vue 3 和 Vite 搭建，文章存在 Markdown 文件里，没有后台，也没有数据库。

## 为什么选择静态网站

静态网站的好处很朴素：构建之后就是一组 HTML、CSS 和 JavaScript 文件，放在任何地方都能运行。它不需要服务器一直醒着，也不会有“数据库连接失败”这样的深夜消息。

对个人写作来说，这几乎已经够了。文章不常修改，读者也不需要登录。把复杂度降下来之后，剩下的注意力就可以还给内容本身。

## 把内容留在 Markdown 里

每篇文章都是一个普通的 `.md` 文件。想写东西时，新建文件、填写日期和标题，然后开始写。页面会在构建时自动找到这些文件，按日期排好，放进对应的专栏。

这种约定比“先打开后台，再点新建”更适合我。写作本来就容易被打断，能少一步操作，就多一分坐下来写完的可能。

## 给以后留一个入口

我特意把专栏配置单独放在一个文件里，并写好了注释模板。以后如果突然想增加一个“旅行”或“随手拍”专栏，只需要加一条配置、建一个文件夹，不用碰页面代码。

一个网站不必一开始就长得很大。重要的是，它应该有一个清楚、轻便的入口，让下一次更新不会变成负担。

这大概就是“安静”的含义：不急着展示什么，只是始终留着一盏灯。
